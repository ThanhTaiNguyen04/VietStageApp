RhythmStaffDisplay uses the scoring font (not Bravura Text): four staff
spaces per em, with the G-clef origin on G4. Time-signature digits use
SMuFL U+E080–E089, centered on the upper and lower halves of the staff.
Font reference: https://smufl.formats.music/latest/tables/time-signatures.html
