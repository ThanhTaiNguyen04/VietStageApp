# Kayageum/Guzheng reference samples

The optional WAV files in this directory are sourced from the **kayageum1**
sample pack recorded by Freesound user **spt3125**.

- Source: https://freesound.org/people/spt3125/packs/1534/
- License: Creative Commons Zero 1.0 (CC0-1.0)
- Retrieved/verified: 2026-07-17
- Recording notes: individual plucked strings, 44.1 kHz stereo source files

Expected normalized filenames:

- `G3.wav` from `kayageum1_G3.wav`
- `A3.wav` from `kayageum1_A3.wav`
- `C4.wav` from `kayageum1_C4.wav`
- `D4.wav` from `kayageum1_D4.wav`
- `E4.wav` from `kayageum1_E4.wav`
- `G4.wav` from `kayageum1_G4.wav`
- `A4.wav` from `kayageum1_A4.wav`
- `C5.wav` from `kayageum1_C5.wav`

Normalize each asset to mono, 44.1 kHz, 16-bit PCM, peak -3 dBFS, with
leading silence removed and short attack/release fades. If any file is absent
or cannot be imported, VietStage automatically uses its built-in
Karplus-Strong plucked-string synthesis for that pitch.

These recordings are a timbral approximation (Kayageum/Guzheng family), not
recordings of a Vietnamese đàn tranh. UI copy must refer to them as “âm thanh
mẫu”, not as an authentic đàn tranh recording.
